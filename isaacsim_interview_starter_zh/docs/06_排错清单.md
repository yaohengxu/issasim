# 排错清单

## 启动失败或 import 失败

- 从 Isaac Sim 安装根目录用 `python.bat` 启动，而不是系统 `python.exe`。
- `SimulationApp(...)` 必须先于 `omni.*` / `isaacsim.*` API import。
- `--headless` 只用于无界面运行；GPU/驱动与安装版本也需要匹配。

## 找不到资产

- 检查 `get_assets_root_path()` 是否返回路径。
- 先运行安装目录的 `post_install.bat`。
- 首次加载官方资产需要网络；确认资产路径与当前版本一致。

## 物体不下落或不能碰撞

- 是否只创建了 visual，没有 rigid body/collider？
- 是否有地面 collider？
- 是否在 `world.reset()` 后推进了物理帧？
- 是否每帧直接 set pose，把物理结果覆盖掉？

## 机器人不动

- Prim path 与 USD 中的 articulation root 是否一致？
- 是否在 reset 后取得 controller？
- action 的关节顺序、单位、维度是否匹配？
- 是否 `world.is_playing()`，以及仿真循环是否真的在 step？

## 必须记录的诊断量

每秒打印而非每帧打印：step、dt、关节位置/速度、末端 pose、目标误差、夹爪宽度、接触状态、物体速度、成功/失败原因。遇到物理问题，先保存最小 USD/脚本和随机种子。
