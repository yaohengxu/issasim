# 文档导航：以工程闭环组织 Isaac Sim 知识

这不是 API 字典，而是一套用于面试与落地开发的知识地图。建议沿箭头阅读；每一层都要能说出输入、输出、失效模式和验证方法。

```text
                         ┌──────────────────────────┐
                         │  需求 / 成功指标 / 安全约束 │
                         └────────────┬─────────────┘
                                      │
┌───────────────┐    USD 资产/场景    ▼       action      ┌──────────────────┐
│ 资产与场景制作 │ ─────────────────► Isaac Sim ◄──────── │ 控制器 / 策略 / ROS │
│ mesh/USD/材质  │                    │  Kit + USD + PhysX│ └──────────────────┘
└───────────────┘                    └───────┬──────────┘
                                             │ render / state / contacts
                         ┌───────────────────▼───────────────────┐
                         │  观测、日志、reward、成功判定、回归测试 │
                         └───────────────────┬───────────────────┘
                                             │
                                   ┌─────────▼─────────┐
                                   │ 真机标定与 Sim-to-Real │
                                   └───────────────────┘
```
