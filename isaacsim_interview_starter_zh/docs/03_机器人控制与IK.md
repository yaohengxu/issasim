# 机器人控制、FK 与 IK

## 从关节到末端：FK

给定关节角 `q`，正向运动学输出末端位姿：`x = f(q)`。关节编码器提供 `q`，FK 让控制器知道手在哪里。

## 从末端目标到关节：IK

逆运动学要找 `q*` 使 `f(q*)` 接近目标位姿。冗余机械臂（如 Franka 7 自由度）通常有多解，还要考虑关节限位、碰撞、奇异点和姿态偏好。

### Jacobian 与差分 IK

局部线性化：`dx = J(q) dq`。一个常用的阻尼最小二乘（DLS）更新是：

```text
dq = Jᵀ (J Jᵀ + λ² I)⁻¹ dx
q_target = q_current + α dq
```

- `λ`：阻尼，奇异附近避免数值爆炸；
- `α`：步长，过大可能震荡或触碰障碍；
- 实际系统还应夹紧关节范围、速度与加速度。

`demos/03_differential_ik_math.py` 展示纯 NumPy 版本；现有 `franka_wave_demo.py` 将它接到真实 articulation Jacobian。

## 控制层次

| 层次 | 输入 | 优点 | 风险/场景 |
| --- | --- | --- | --- |
| 位置控制 | `q_target` | 最容易上手，稳定 | 不能直接表达接触力 |
| 速度控制 | `q_dot_target` | 轨迹跟踪自然 | 对频率、滤波敏感 |
| 力矩控制 | `tau` | 能做阻抗/力控 | 需动力学与安全处理 |
| 笛卡尔阻抗 | 末端 pose/刚度 | 接触任务常用 | 参数不好会振荡 |

面试时说明：底层多数机器人有 PD/drive；上层 IK/RL policy 给出目标；不要把“设置关节位置”误称为力矩控制。

## 抓放状态机

一个清晰的 pick-and-place 不必一开始就端到端学习：

```text
open → pre-grasp → approach → close → verify grasp → lift → pre-place → release → verify
```

每个状态要有入口条件、超时、失败恢复和可量化观测。例如 `verify grasp` 可检查物体相对末端的位姿、夹爪宽度、接触/力信息和抬升后的持续跟随。
