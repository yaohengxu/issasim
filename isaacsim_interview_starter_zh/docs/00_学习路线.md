# 学习路线：先建立一张地图

## 你需要能回答的五件事

1. **世界如何表示？** USD Stage 是场景图；Prim 是节点；参考（reference）、层（layer）、变体（variant）让资产可复用。
2. **世界如何动起来？** PhysX 根据质量、碰撞体、关节、摩擦、重力和时间步推进状态。
3. **机器人如何动作？** 通过 articulation 读取关节状态，再向关节位置/速度/力矩驱动器发送 action。
4. **任务如何闭环？** 传感器或状态给出 observation，控制器/策略给出 action，奖励或成功条件评价结果。
5. **为何仿真能迁移现实？** 不能天然保证；必须校准，并通过 domain randomization、观测噪声和执行延迟让策略不依赖“完美仿真”。

## 最小闭环

```text
USD 场景 + 机器人
        ↓
PhysX step(dt) ─→ 相机/关节/接触观测
        ↑                    ↓
  articulation action ← 控制器、IK 或 RL policy
        ↓
   成功条件 / reward / 日志
```

## API 心智模型

- `SimulationApp`：启动 Kit；**必须在 Omniverse/Isaac API import 前创建**。
- `World`：管理场景、reset 和 step。
- `scene.add(...)`：登记可通过名称访问的对象包装器。
- `Articulation` / `SingleManipulator`：多关节机器人包装器。
- `world.reset()`：初始化物理与对象状态；机器人加载后通常都要调用。
- `world.step(render=...)`：推进一帧。循环中不应只改 USD pose 来伪造物理。

## 阅读优先级

| 优先级 | 主题 | 面试价值 |
| --- | --- | --- |
| P0 | USD、PhysX、时间步、Articulation | 基础必问 |
| P0 | FK/IK、Jacobian、位置/力矩控制 | 操作任务必问 |
| P1 | 相机、坐标系、标定、观测 | 视觉具身高频 |
| P1 | 抓取状态机、奖励、成功判定 | 体现工程闭环 |
| P1 | 随机化与 Sim-to-Real | 能区分“会跑 demo”和“会做项目” |
| P2 | Replicator、ROS 2、Isaac Lab | 根据岗位准备 |

不要把 Isaac Sim 说成训练算法本身：它更像高保真仿真、合成数据和验证平台；RL 训练常由 Isaac Lab 等上层任务/训练框架承担。
