# 智驾仿真平台工程师 / 专家：岗位对标知识工程

面向“Simulation 仿真引擎、场景生成、世界模型、强化学习、合成数据、传感器仿真、自动驾驶、C++/Python”的平台研发岗位。本目录将 JD 转换成可学习、可展示、可面试的工程能力。

## 你需要讲清的一条主线

```text
真实道路数据 / 需求
       │
       ▼
场景资产 + 场景生成 + 数据回灌
       │
       ▼
仿真执行器（物理、交通、传感器、时钟）
       │
       ├──> 被测系统：感知 → 预测 → 规划 → 控制
       │                         │
       └──── 闭环 action ────────┘
       │
       ▼
指标、回放、失败聚类、覆盖率、报告
       │
       ▼
场景库 / 模型 / 回归集持续迭代
```

**平台价值**不在于“跑一次漂亮仿真”，而在于让算法团队可以稳定、可扩展、可复现地回答：改动是否变好、在哪类危险场景失败、失败是否可回放、怎样修复和防回归。

## 与现有 Isaac Sim 学习工程的关系

| 现有工程能力 | 对应智驾平台能力 | 下一步 |
| --- | --- | --- |
| USD、PhysX、Articulation | 场景/资产与物理引擎基础 | 扩展到道路、车辆与传感器 |
| 控制循环、评测 predicate | 闭环执行与指标基本形式 | 接入被测 AD stack 与多场景批跑 |
| 传感器、随机化、合成数据概念 | 传感器仿真和数据生成入口 | 建立标注、质量与数据版本流水线 |
| headless demo、seed、日志 | 可复现执行基础 | 增加调度、回放、资源治理、CI |

不要把“会 Isaac Sim GUI”说成“已具备专家级智驾仿真平台能力”。专家岗位还要求大规模执行、确定性、数据/场景治理、系统接口和跨团队交付。本目录会告诉你如何诚实地展示当前能力与下一步计划。
