# 学习路线与差距评估

## 先面对岗位级别

该 JD 的“3 年以上、平台架构、并发、传感器、世界模型”是中高级/专家导向。若你是 Isaac Sim 初学者，短期目标应是：**展示可靠的学习能力、正确的系统抽象和一个可复现闭环作品**；不要假装已有生产级规模经验。

## 四周高优先级路线

### 第 1 周：仿真编程闭环

- 完成现有 Isaac Sim 工程的 `01 → 04` demo；
- 会解释 `SimulationApp → Stage/USD → World/Articulation → action → step → evaluator`；
- 写一个 JSON config 和 headless runner；
- 目标：固定 seed 下可重复输出同一类指标。

### 第 2 周：平台工程基本功

- Python：`dataclass`、logging、argparse、JSONL、pytest、subprocess；
- Linux：进程、日志、文件句柄、GPU 工具、Docker 基础；
- C++：RAII、智能指针、move、线程池、future/promise、producer-consumer；
- 目标：批跑 10 个 scenario，失败不阻塞整体，生成 summary。

### 第 3 周：智驾仿真语义

- 学习 ODD、open/closed loop、TTC/碰撞/舒适性指标；
- 接触 CARLA/ROS2 的基本概念或至少完成接口设计；
- 读 camera/lidar/radar 建模差异；
- 目标：可以设计一个 cut-in 场景和评测 contract。

### 第 4 周：数据和前沿话题

- 合成数据随机化、标注 schema、质量审查；
- RL 的 Env contract、reward、vectorization；
- 世界模型/3DGS/Diffusion：理解接入和验证边界，不要求从零训练；
- 目标：写一页“生成场景接入平台”的设计说明。
