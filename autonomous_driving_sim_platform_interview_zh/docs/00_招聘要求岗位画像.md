# 岗位画像：智驾仿真平台工程师 / 专家

## 岗位目标

构建支撑自动驾驶研发的仿真平台，使感知、预测、规划、控制模型能够在大规模、可复现的虚拟场景中完成闭环验证。平台的价值由场景覆盖、传感器/世界真实性、执行吞吐、评测可信度和问题定位效率共同决定。

## 工作职责（结构化版）

```text
仿真平台
├─ 仿真引擎、场景生成、闭环评测架构
├─ 高性能执行：并发调度、资源管理、回放、数据回灌
├─ AI 生成能力：合成数据、自动场景、RL、世界模型接入
├─ 传感器：camera / lidar / radar 多模态建模
└─ 工程交付：文档、规范、CI、监控、跨团队 SDK
```

### 需要承担的核心工作

1. 设计和研发高保真、可扩展的仿真引擎、场景生成与评测体系。
2. 支撑感知、预测、规划、控制模块的闭环测试与回归。
3. 建设多线程/并发调度、任务执行、确定性回放、数据回灌、资源和指标监控能力。
4. 将合成数据、自动场景创建、RL 环境，以及 3DGS/Diffusion/世界模型等 AI 能力安全接入。
5. 覆盖摄像头、激光雷达、毫米波雷达等传感器建模与多模态数据质量。
6. 维护平台文档、流程、自动化测试和跨团队交付质量。

## 优先项

```text

```

## 面试官的隐含期待

这个岗位不是单点算法岗位。对工程师，期待你能把一个仿真能力变成可用服务；对专家，期待你能定义平台边界、技术路线、保真度/成本取舍和跨团队标准。阅读顺序：先看 `01_JD能力矩阵.md`，再看 `02_智驾仿真平台架构.md`。
