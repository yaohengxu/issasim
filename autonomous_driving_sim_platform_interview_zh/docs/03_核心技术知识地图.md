# 核心技术知识地图

## 1. 仿真引擎与实时系统

```text
世界状态 x(t)
  │  dynamics / traffic / rules
  ▼
x(t + dt) ──> sensors ──> AD stack ──> action ──> next x
```

要掌握：离散时间步、固定/可变 `dt`、substep、坐标系、单位、物理/渲染频率、确定性边界、实时率（RTF）。

- **SIL**：software-in-the-loop，软件栈接仿真。
- **HIL**：hardware-in-the-loop，硬件 ECU/传感器/总线接仿真。
- **MIL**：model-in-the-loop，控制/模型级验证。
- **Open loop**：回放数据，算法输出不反馈世界。
- **Closed loop**：算法 action 改变未来世界，适合规划控制验证。

## 2. 智驾场景与 ODD

```text
ODD 维度
├─ 道路：高速/城区/匝道/路口/车道拓扑
├─ 交通：密度、速度差、cut-in、行人、异形目标
├─ 环境：昼夜、雨雾、光照、路面状态
├─ Ego：初速度、传感器状态、软件版本
└─ 事件：急刹、遮挡、施工、信号灯、冲突时机
```

场景不是“一个视频”。一个可运行 scenario 应包含初始条件、参与者行为、触发条件、预期/禁止行为、评测器、seed 和资产版本。场景库要能做检索、去重、版本化、覆盖统计和失败回灌。

## 3. 传感器仿真

| 传感器 | 建模重点 | 常见错误 |
| --- | --- | --- |
| Camera | 内外参、曝光、畸变、运动模糊、滚动快门、材质/光照 | 只追画质，不验证几何/时间对齐 |
| LiDAR | beam pattern、FOV、range、反射、遮挡、噪声、时间扫描 | 当作瞬时无噪点点云 |
| Radar | 距离/速度/角度分辨率、RCS、多径、虚警 | 用“稀疏点云”代替雷达语义 |
| GNSS/IMU | 频率、延迟、漂移、噪声、坐标系 | 直接喂全局真值 |

保真度按任务评价：例如检测需要视觉外观与标注准确，紧急制动需要 range/latency/遮挡可信；不是所有传感器都需要同级别的光线追踪。

## 4. 数据驱动与生成式能力

```text
真实日志 ─→ 场景挖掘 / 参数拟合 ─→ 规则场景 + 生成场景
                                        │
3DGS / Diffusion / World Model ──────────┤  条件生成
                                        ▼
                              validity filter / physics / rules
                                        ▼
                              仿真与闭环评测
```

生成模型进入平台前必须处理：条件输入、输出格式、坐标/尺度、时序一致性、可控性、物理合法性、异常检测、成本和降级方案。世界模型生成的轨迹或外观不能天然代替因果交通规则和安全验证。

## 5. RL 与多智能体

```text
Env.reset(seed) → obs
Env.step(action) → next_obs, reward, terminated, truncated, info
```

RL 平台重点是批量环境、reset 吞吐、奖励/终止规范、观测和动作归一化、随机化、checkpoint 评测及防 reward hacking。多智能体增加 actor policy、通信、同步、credit assignment 与 non-stationarity；首先明确谁是 ego、谁可控、谁遵守规则。

## 6. C++ / Python / GPU 的合理分工

| 工作 | 常用选择 | 原因 |
| --- | --- | --- |
| 高性能循环、仿真内核、网络 IO | C++17+ | 延迟、内存控制、RAII、并发 |
| 调度、配置、数据处理、原型、评测 | Python | 开发效率、生态、可读性 |
| 模型推理/张量、批处理 | CUDA/TensorRT/PyTorch | GPU 吞吐 |
| 渲染/传感器 | Unreal/RTX/Vulkan/OpenGL 等 | 图形管线与着色能力 |

“Python 慢所以全部 C++”是错误取舍。先 profile；高频数据路径可 C++/zero-copy，控制面和实验编排用 Python 通常更合适。
